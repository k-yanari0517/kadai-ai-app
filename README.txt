画像キャプション生成AI

1. プロジェクト概要
本プロジェクトでは、アップロードされた画像の内容をAI（Deep Learning）が解析し、自動で英文キャプションを生成するWebアプリケーションを構築しました。開発環境から本番環境（AWS EC2）までの一貫したポータビリティを確保するため、DockerおよびDocker Composeを活用したマルチコンテナ構成を採用しています。

2. システム構成・使用技術
実務的なWebシステムを意識し、アプリケーションサーバーとデータベースサーバーを分離した構成としています。

フロントエンド / バックエンド: Python (Flask)

AIエンジン: Hugging Face ViT-GPT2 モデル（画像解析・文章生成）

データベース: PostgreSQL 15（データの永続化とスケーラビリティの確保）

インフラ: AWS EC2 (Ubuntu), Docker, Docker Compose

WSGIサーバー: Gunicorn（本番環境用）

3. 構築およびデプロイ手順
EC2インスタンス作成後、以下の手順でデプロイ作業を実施しました。

環境構築: EC2へDockerおよびDocker Composeをインストールし、実行権限の設定を行いました。

ソースコード配置: GitHubリポジトリより最新のソースコードをクローンしました。

コンテナ起動: docker compose up -d --build コマンドを実行。Dockerfileに基づき、AIモデルのダウンロードを含むWebイメージのビルドと、PostgreSQLコンテナの初期化を自動で行いました。

ネットワーク設定: AWSのセキュリティグループにて、Flaskが待機する 8000番ポート を開放し、外部ブラウザからのアクセスを許可しました。
